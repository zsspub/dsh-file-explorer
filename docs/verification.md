## 真实端到端结果

| 场景                                   | 结果                                                |
| -------------------------------------- | --------------------------------------------------- |
| 会话标题“文件”入口                     | 打开 overlay 右侧抽屉，未占用详情栏                 |
| 真实产物、正文文件引用、工具 read 卡片 | 三类入口均打开同一真实文件                          |
| Markdown、代码、HTML、PNG              | 分别显示渲染内容、高亮行号、源码、图片              |
| 目录与额外根目录                       | 切换后读取正确文件；处理 macOS 真实路径别名         |
| 刷新页面                               | 抽屉关闭，再次打开读取正确内容                      |
| 切换会话                               | 旧抽屉关闭，返回原会话可重新打开                    |
| Escape、Tab、Shift+Tab                 | 关闭恢复触发入口焦点；焦点在抽屉内循环              |
| 遮罩与关闭状态                         | 点击遮罩后 dialog 数量为零，页面可再次交互          |
| 480 × 800 窄屏                         | 抽屉全宽，目录树可收起                              |
| Host 授权读取                          | 工作区/额外目录 200，越界 403，缺失 404，未认证 401 |
| 停用插件并刷新                         | “文件”入口消失，产物点击调用原生打开 RPC            |
| 恢复插件                               | 三类入口再次打开抽屉                                |

停用后的原生 RPC 返回 `opened: true`；该结果证明 Host 接受原生打开操作，不声称验证了系统应用内部画面。生命周期卸载恢复另外由真实 Cordis 测试覆盖。权限不足、大小上限、快速并发请求等错误/竞态路径以自动化测试或实现检查为证据，未逐项录制浏览器画面。
